AI FIELD

Models · Tools · Harnesses

🚀 SpaceX
+ Cursor ×
  • SpaceX adopted Cursor as primary AI dev environment across engineering teams
  • Cursor runs Claude Sonnet 4.6 — 97.6% HumanEval, full repo awareness
  • Highest-profile enterprise validation of AI-assisted coding to date
  • SpaceX has resources to run local models — chose cloud anyway
  • That decision settles the local vs. cloud debate for serious engineering orgs
⚙️ AI
Harness ×
  • Harness = wrapper around a model — input in, rules enforced, output out
  • Simplest: system prompt + API call — ~20 lines of Python
  • Complex: fine-tuning, multi-head attention, hardware-optimized inference
  • The gap between 20 lines and 200,000 is your use case, not the model
  • Start at 20 lines. Only add complexity when you hit a concrete wall
🧠 BERT
2018 ×
  • Google 2018 — reads text in both directions simultaneously, unlike GPT
  • Masks words, predicts from surrounding context: "My [MASK] is cute" → dog
  • Powers Google Search semantic understanding — still running at global scale
  • Simple build: pip install transformers → bert-base-uncased → classify
  • Most devs don't touch it directly — it's the plumbing behind search and NLU
