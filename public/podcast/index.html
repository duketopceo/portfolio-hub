AI harnesses · the simple version

An AI harness is a wrapper around a model. Input goes in. Rules enforced. Output comes out. The simplest harness is a system prompt + an API call — about 20 lines of Python.

BERT (Google, 2018) reads text in both directions simultaneously. It masks words and predicts them from surrounding context. Example: "My [MASK] is cute, he's playing." → BERT predicts "dog." This is what powers Google Search's semantic understanding layer.

Simple build: pip install transformers → load bert-base-uncased → .encode() → classify. Complex build: fine-tune on domain data, multi-head attention layers, hardware-optimized inference. The difference is 20 lines of code vs. 200,000.
