AI FIELD

Models, Tools, Harnesses

HOW AI IS ACTUALLY BEING USED RIGHT NOW

  • SpaceX adopted Cursor as primary AI dev environment across engineering teams
  • Cursor runs Claude Sonnet 4.6 — 97.6% HumanEval, full repo awareness
  • Highest-profile enterprise validation of AI-assisted coding to date
  • The real signal: SpaceX has resources to run local models — they chose cloud
  • That one decision settles the local vs. cloud debate for serious engineering orgs
  • Harness = wrapper around a model. Input in, rules enforced, output out
  • Simplest harness: system prompt + API call — about 20 lines of Python
  • Complex harness: fine-tuning, multi-head attention, hardware-optimized inference
  • The difference between 20 lines and 200,000 is your use case, not the model
  • Start at 20 lines. Only add complexity when you hit a concrete wall
  • Google 2018 — reads text in both directions simultaneously, unlike GPT
  • Masks words and predicts from surrounding context: "My [MASK] is cute, he's playing" → dog
  • Powers Google Search's semantic understanding layer — still running at global scale
  • Simple build: pip install transformers → bert-base-uncased → .encode() → classify
  • Most devs don't touch BERT directly — it's the plumbing behind search and NLU
